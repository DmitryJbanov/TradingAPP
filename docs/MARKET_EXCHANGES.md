# Источник данных фьючерсного графика

В заголовке страницы графика доступен выбор **Binance, OKX, Bybit, MEXC**. Выбор сохраняется в текущем профиле (`vector.exchange.v1`), по умолчанию — Binance. При переключении сохраняются инструмент и таймфрейм; график и индикаторы пересчитываются по свечам новой биржи. Поиск и котировки бокового списка также используют выбранную площадку. Поддерживаются действующие линейные бессрочные контракты USDT/USDC.

Если контракт отсутствует или API недоступен, отображается ошибка. Автоматической подмены данных другой площадкой нет. CoinGlass, Fear & Greed, RSI Heatmap и Hyperliquid остаются независимыми источниками аналитики. Главный обзор рынков сохраняет свой прежний набор источников, включая Twelve Data.

## API

Параметр `exchange=binance|okx|bybit|mexc` поддерживается маршрутами:

- `/api/markets` — цены и изменения за 24 часа.
- `/api/markets/favorites?symbols=BTCUSDT,FUTURES:ETHUSDT` — выбранные котировки.
- `/api/symbols?q=BTC` — поиск бессрочных контрактов.
- `/api/candles?symbol=FUTURES:BTCUSDT&interval=4h&count=1000` — история (300–12000 свечей).
- `/api/candles/latest?symbol=FUTURES:BTCUSDT&interval=4h` — две последние свечи.

Ответ свечей содержит `exchange`, `provider`, `source=live`, `tickSize` и нормализованные OHLCV. Время — Unix seconds UTC, объём — в базовом активе. OKX использует `volCcy`, MEXC переводит контракты в базовый объём через `contractSize`. Запросы ограничены фиксированными адресами API; произвольные URL не принимаются. Кэш и незавершённые запросы разделены по бирже, паре, интервалу и размеру истории.

Пагинация движется в прошлое, сортирует и удаляет дубли. Недоступная или короткая история обозначается предупреждением. Отсутствующие нативные интервалы агрегируются из свечей той же биржи: MEXC 3m из 1m, 2h из 1h, 12h из 4h; OKX 8h/12h и Bybit 8h из 4h. Для агрегированных интервалов границы заданы в UTC; незавершённая самая старая корзина исключается.

Основной график обновляет последние свечи раз в две секунды. Дополнительная история VMC/SMC/FVG обновляется раз в минуту без отмены предыдущей загрузки из-за каждого ценового тика. Pine `request.security()` получает дневные данные выбранного источника.
