# Общие индикаторы и таймфрейм 4H

Основа патча: коммит `126c1fbe90e233c5c614ada5549aa18c2502a763` ветки main. Это дополнительный патч после обновления свечей и беклога.

Сохраните свои локальные изменения. В корне проекта проверьте: `git apply --check tradingapp-preferences.patch`. Если ошибок нет, примените: `git apply tradingapp-preferences.patch`.

Соберите: `npm run build:standalone`. Остановите старый процесс через Ctrl+C и запустите `npm run start:standalone`. Для Docker: `docker compose up -d --build`.

При открытии пары выбран 4H. Пользователь может переключать таймфреймы как раньше.

Все пары используют общий набор индикаторов из `vector.indicators.shared.v1` в localStorage. Сохраняются состав, порядок, включение/отключение, параметры, стиль и ограничения видимости по таймфреймам. При первом открытии после обновления переносится набор открытой пары из старого `vector.indicators.v1`; если он пуст или содержит только заглушки, берётся первый непустой поддерживаемый набор по алфавиту символов. Старый ключ остаётся резервной копией. Существующий общий набор, в том числе пустой, имеет приоритет. Хранилище относится к текущему браузеру и origin; при запрете localStorage после перезагрузки сохранение недоступно. Одновременное редактирование в разных вкладках не синхронизируется в реальном времени.

Из каталога и активного набора исключены Nadaraya–Watson, SMA и отдельный RSI без реализации. Расчёты RSI внутри VMC сохранены. Доступны VMC, DRZ, SMC и Sonarlab Order Blocks.

Из `src/domain/backlog.ts` удалены выполненные пункты default-timeframe, indicator-persistence, remove-placeholder-indicators. Оставшиеся четыре записи сохранены.
