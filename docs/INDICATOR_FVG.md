# Fair Value Gap · LuxAlgo

В каталоге индикаторов выберите **Fair Value Gap · LuxAlgo**. Он рисует бычьи и медвежьи трёхсвечные дисбалансы на основном графике.

Условия формирования совпадают с описанием LuxAlgo: бычий FVG — минимум текущей свечи выше максимума свечи две позиции назад, а закрытие предыдущей выше этого максимума; медвежий — максимум текущей ниже минимума две позиции назад и предыдущее закрытие ниже него. Auto Threshold сравнивает относительный размер gap со средним размером найденных gap; при выключенном автофильтре используется заданный Threshold %.

В настройках доступны таймфрейм графика/старший таймфрейм, Auto Threshold и порог, Dynamic-обновление границ при частичном заполнении, число уровней незаполненных зон, показ уровней заполненных зон и отдельные цвета для bullish/bearish FVG. Старший таймфрейм используется после закрытия свечи.

Расчёт реализован в `src/indicators/fvg.ts`, параметры — `src/indicators/fvg-settings.ts`; загрузку истории старшего таймфрейма выполняет `src/hooks/use-overlays.ts`. Описание исходного индикатора: [Fair Value Gap [LuxAlgo] на TradingView](https://www.tradingview.com/script/jWY4Uiez-Fair-Value-Gap-LuxAlgo/).

Это самостоятельный перенос описанной логики, а не выполнение Pine Script или встроенный TradingView widget.
