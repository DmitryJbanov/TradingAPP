# Пресеты индикаторов

В окне настроек каждого индикатора есть блок «Пресеты». Он доступен для стандартных индикаторов, карт CoinGlass и собственных Pine-индикаторов и стратегий.

## Использование

1. Настройте параметры и оформление, введите название и нажмите «Сохранить новый».
2. Выберите сохранённый пресет и нажмите «Применить». В окнах с отдельной кнопкой применения подтвердите изменения кнопкой внизу окна.
3. «Обновить» сохраняет текущие настройки в выбранный пресет. «Переименовать» меняет название, «Удалить» удаляет пресет.
4. Включите «Использовать по умолчанию при добавлении индикатора». Новый экземпляр этого индикатора получит его параметры. Существующие экземпляры сохраняют свои настройки. Для возврата к встроенным стандартным параметрам снимите флажок.

Сохраняются параметры расчёта, оформление, цвета, иконка и ограничения по таймфреймам, доступные у индикатора. Состояние видимости и расположение экземпляра не копируются. Снимки CoinGlass не входят в пресет; для нового периода карту нужно загрузить отдельно.

## Хранение

В standalone пресеты входят в выбранный профиль: общий или личный. Они синхронизируются вместе с настройками профиля и сохраняются в SQLite под ключом `vector.indicator-presets.v1`. В варианте без серверных профилей используются настройки браузера.

Пресеты разделены по типам индикаторов. Для Pine каждый сохранённый скрипт имеет отдельный набор пресетов по своему ID. Удаление пресета по умолчанию возвращает встроенные настройки для новых экземпляров.

Сервер проверяет структуру и размеры данных: до 200 пресетов в профиле, название до 80 символов, один пресет до 64 000 символов, весь набор до 1 000 000 символов JSON.
