# CoinGlass Heatmap · Model 3

Документ для актуальной Model 3. Индикатор добавляется на странице пары через список индикаторов; период выбирается в настройках/панели индикатора. Сбор запускается при открытии графика с активной картой и вручную кнопкой подгрузки. Ручной импорт JSON в этом интерфейсе отключён.

Период «2 недели» использует прямой запрос CoinGlass 14d; загрузка и обрезка 30-дневного источника не используются.

## Отображение

Карта хранит ячейки по времени и цене. На графике каждая ячейка располагается в соответствующей исторической точке, а не растягивается на весь видимый диапазон. Отрисовка ограничена интервалом, для которого загружены свечи. Пересчёт координат учитывает дробное положение между свечами и выбранный timeframe, поэтому короткие периоды имеют ту же историчность, что и 180/365 дней.

Цветовая интенсивность соответствует значению ячейки и выбранной палитре/шкале. Масштабирование графика и изменение таймфрейма пересчитывают видимую проекцию. Настройки могут скрыть overlay, не меняя данные самого индикатора и отдельный блок кумулятивного объёма. Скрытие индикатора из списка также отключает его графические слои.

## Настройки и данные

Настройки индикатора включают период, минимальную выраженность, шкалу/палитру, видимость на основном графике и параметры кумулятивного объёма. Точные значения по умолчанию проверяйте в текущем окне настроек; структура снимка и допустимые периоды определяются типом `HeatmapParams` в `src/domain/heatmap.ts`.

Сбор выполняет сервис `coinglass` с Playwright/Chromium. Успешные снимки хранятся в Docker volume `coinglass-data`; ошибка нового сбора не должна заменять последний успешный снимок. Для работы нужны сетевой доступ к CoinGlass и доступная пользовательская сессия/учётная запись, если сайт этого требует.

## Производительность Model 3

Ячейки индексируются по временным колонкам без сокращения данных. При панорамировании обходятся только видимые колонки; координаты временных границ и оформление ячеек кешируются. На основном графике готовый слой сохраняется в OffscreenCanvas в разрешении текущего DPR: движение курсора повторно выводит изображение без пересчёта всех ячеек. Масштаб, ценовая ось, размер окна, история, порог и палитра сбрасывают соответствующий кеш. В браузерах без OffscreenCanvas используется прямая отрисовка. Предпросмотр объединяет изменения в кадры requestAnimationFrame. Статистика снимка вычисляется один раз, а сортировка объёмов выполняется только для шкалы перцентилей.

Проверка на 1 000 000 синтетических ячеек (600 500 видимых): медиана повторной подготовки кадра JavaScript — 225,4 мс до оптимизации и 1,82 мс после. Это измерение с тестовым Canvas, не замер GPU или FPS браузера. Команды рисования, цвета, прозрачность и порядок совпадают с прежним renderer; сокращение/усреднение ячеек не применяется.

## RSI Heatmap: данные и порядок

RSI и цены берутся из ответа `/api/index/rsiMap`, который использует график CoinGlass; значения из отдельной spot-таблицы не смешиваются с картой. Состав top 50 фиксируется по исходному рангу CoinGlass до проверки RSI. Отсутствующий недельный RSI не заменяет инструмент следующим по списку: для него показывается «—». Все три периода сохраняются в одном снимке и переключаются локально. Капитализация загружается через клиент CoinGlass из общего рейтинга и всех страниц crypto market-cap; инструменты располагаются слева направо по исходному рангу карты CoinGlass. Капитализация используется только в подсказке. Объём торгов не является заменой капитализации. Старые снимки автоматически обновляются до rsiRevision=3. Вертикальное положение точки соответствует RSI выбранного периода на шкале 10–90. Короткая пунктирная линия соединяет RSI и RSI минус изменение цены за этот период в процентах; положительное изменение обозначается зелёным, отрицательное — красным. Цвет точки соответствует зоне RSI.
