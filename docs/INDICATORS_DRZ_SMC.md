# История, HYPE, DRZ и SMC

## Поведение и параметры

Количество загружаемых и используемых при расчёте свечей: любое целое 300–4000, default 1000. Изменение применяется по Enter/галочке, хранится в localStorage `vector.candles.v1`. Масштаб обновляется при смене глубины/таймфрейма; фоновое обновление сохраняет пользовательский масштаб. Минимальный шаг отрисовки позволяет вместить 4000 свечей в рабочую область.

DRZ и SMC добавлены в общий менеджер. У каждого экземпляра свои аргументы, цвета и видимость на 15m/1h/4h/1d. Работают несколько экземпляров, порядок, отключение, удаление, отмена черновика, сброс и сохранение в существующем `vector.indicators.v1`. Sonarlab сохранён.

Стандарт VMC по скриншотам: WT Close, 9/12/3; OB 5/45/0, OS 0/−45/0; gold выключен; regular/hidden WT divergences включены, пороги 45/−45, второй набор выключен (15/−40). MFI включён, 60/150/2.5. RSI выключен (Close, 14, 30/60, дивергенции выключены). Stoch выключен (Close, 14/14/3/3, log и average выключены). Schaff выключен (Close, 10/23/50, 0.5). Sommi flag/wave/diamond и MACD colors выключены; TF 720, 60/240 и 240, пороги Sommi 0. Существующие пользовательские значения сохраняются; сброс применяет новый стандарт.

## API и источники

`GET /api/candles?symbol=HYPEUSDT&interval=1h&count=4000`

count необязателен (1000), принимает 300–4000 целых; иначе HTTP 400. Ответ сохраняет data/source/provider/asOf/warning и дополняется необязательным tickSize — PRICE_FILTER биржи. `demo=1` и `refresh=1` поддерживаются. Ключ кэша включает count, TTL 15 секунд, максимум 64 записи. Опрос не обрывает незавершённый запрос большой истории. Смена URL исключает отображение старой пары/ТФ как новой.

Binance Spot использует `/api/v3/klines`; HYPEUSDT — **perpetual** Binance Futures, `/fapi/v1/klines`, `/fapi/v1/ticker/24hr`, `/fapi/v1/exchangeInfo` на fapi.binance.com. Ключи для этих публичных запросов не нужны. HYPE исключён из batch спотовых тикеров. [Официальное объявление HYPE](https://www.binance.com/en/square/post/24935949927994), [Binance Spot API](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/rest-api/market).

Binance загружается назад страницами до 1000 строк. Следующий endTime = oldestOpenTime − 1 ms. OHLCV проверяется, сортируется и дедуплицируется. Если старая страница недоступна, свежая часть остаётся live с предупреждением; если пригодных данных нет, включается явно отмеченный DEMO. Twelve Data получает запрошенный outputsize. История может быть короче из-за даты листинга или ограничений провайдера.

VMC/SMC запрашивают тот же count для вспомогательных таймфреймов. Смешивание demo/live или разных провайдеров запрещено: зависимые элементы скрываются с предупреждением. Последняя свеча может быть незакрытой.

## Архитектура и стек

Сохраняются React 19, TypeScript 5, Lightweight Charts 5.0.9, существующие Radix/Shadcn, Fetch backend, standalone Node и Cloudflare. Новых npm-зависимостей нет.

| ---------------------------------------- | ---------------------------------------------------------- |
| `domain/history.ts`                      | Границы, default и нормализация count                      |
| `server/binance-history.ts`              | Spot/futures routing, обратная пагинация, partial results  |
| `components/history-count.tsx`           | Поле глубины с явным применением                           |
| `indicators/drz.ts`, `smc.ts`            | Чистые расчёты по OHLCV, без сети/DOM                      |
| `indicators/*-settings.ts`               | Типы, default, схемы полей и нормализация                  |
| `indicators/overlay-model.ts`            | Геометрия, сигналы, ATR и преобразование времени в индексы |
| `hooks/use-overlays.ts`                  | MTF-зависимости, abort, проверка источников, мемоизация    |
| `indicators/price-overlays-renderer.ts`  | Primitive, заливки под свечами, линии/метки, clipping      |
| `components/overlay-settings-dialog.tsx` | Аргументы, стиль, видимость, apply/cancel/reset            |
| `domain/workspace.ts`                    | Реестр и сериализуемые параметры экземпляров               |

`computeDrz(bars, params, {tickSize})` возвращает зоны, delta/cumulative, геометрию, сигналы, warnings. `computeSmc(bars, params, {interval, histories, now})` возвращает структуры, blocks/gaps, геометрию, candleColors, сигналы, warnings. now ограничивает доступность незакрытых HTF. `requiredSmcIntervals` определяет сетевые зависимости отдельно от расчёта. Геометрия выражена в индексах и ценах, поэтому следует за обеими осями. Из нескольких SMC последняя включённая окраска имеет приоритет. Эти контракты можно использовать для будущих overlay-индикаторов, отдельные осцилляторы продолжают использовать панели VMC.

## DRZ и соответствие Pine

Дельта = sign(close−open)×volume, затем EMA и накопленная сумма либо её RoC. Это оценка OHLCV, не настоящая bid/ask delta. Pivot подтверждается после pivot_length правых свечей; зона привязана к ценовому high/low pivot и ATR на нём. Импульсные доли/net рассчитаны за impulse_window. Совпадающие зоны одного типа объединяются с допуском, расширяющим обе зоны на merge_gap_ticks×tickSize. Пробой close удаляет зону, лимит удаляет старые зоны. RC/RE обозначают пересечение середины выжившей зоны. Отрисованы тело, середина, сегменты, проценты и Δ справа.

При отсутствии биржевого tickSize используется оценка по цене с предупреждением. `tick_size > 0` позволяет задать точное значение вручную. В прогреве net показан как «—»; неизвестный net получает вес 1 при объединении, предотвращая NaN. Это защитное отличие от Pine. RC/RE используют середину конкретной зоны без неоднозначной истории ta.crossover внутри меняющегося массива. Метки ограничены последними 500.

## SMC и соответствие Pine

Реализованы internal leg=5 и swing по параметру; BOS/CHoCH, HH/HL/LH/LL, Strong/Weak extremes; EQH/EQL с ATR200; internal/swing order blocks с ATR/Cumulative Mean Range и Close/High-Low mitigation; FVG; уровни D/W/M; premium/equilibrium/discount; Historical/Present; Colored/Monochrome; окраска свечей.

Confluence сохраняет выражение исходника, включая min(close, open−low). Bearish FVG сохраняет исходную асимметрию: top=currentHigh, bottom=last2Low, удаление high>top. Пробитые блоки удаляются все за бар без пропуска соседнего элемента массива. Хранятся до 100 блоков каждого типа, показывается до 20; линии/метки ограничены 500, активные FVG — 200.

Особенности переноса:

- FVG поддерживает текущий или старший доступный ТФ. Младший ТФ не имитируется, несовместимая сохранённая настройка даёт предупреждение.
- Стандарт `confirmed` ждёт закрытия HTF; сигнал появляется на баре подтверждения. `pine` использует исторический lookahead исходника с предупреждением о перерисовке. На текущем ТФ незакрытая свеча меняется при обновлении в обоих режимах.
- D/W/M — предыдущие завершённые календарные периоды UTC из дневных свечей; месяцы не заменены 30-дневными отрезками. В исходном Pine sameTimeframe на дневном графике берёт текущий high/low; здесь PDH/PDL последовательно означает предыдущий день. Сессии акций могут отличаться от TradingView.
- Начало истории и длина окна влияют на прогрев и результаты. Полная эквивалентность TradingView требует одинаковых OHLCV, календаря и начала истории; сравнение с исполняемым Pine не проводилось.
- Условия сигналов доступны программно, последний сигнал показан под графиком. Внешняя доставка уведомлений не подключена.
