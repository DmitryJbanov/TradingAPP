## Обновления 8 октября 2026

- Главная показывает время котировок в UTC и Москве, а также текущий Fear & Greed из последнего CMC-снимка.
- Для избранных фьючерсов вне базового каталога добавлен пакетный запрос цены и изменения за 24 часа; список избранного на странице графика открывается первым.
- Плашка активного Pine-индикатора открывает его параметры. Добавлена настройка иконки/цвета индикатора и цветов/видимости/стиля графических элементов.
- В таблице публичного рейтинга Hyperliquid сортировка доступна по рейтингу, кошельку, имени, капиталу, PnL и числу позиций.
- Пункт «Киты» получил собственную иконку кита; версия приложения обозначается как **0.5 ALFA**.
