# Как применить vmc-cipher-b.patch

Патч рассчитан на исходную поставку `vector-market-terminal`, коммит `8f3d4697e9f985e646b970616ebf1567138776eb`. Он изменяет исходники и документацию, добавляет VMC Cipher B и его тесты. `package.json`, lockfile и переменные окружения не меняются. GitHub или GitLab не нужны для применения файла, нужен установленный Git.

## Windows / PowerShell

1. Сохраните текущие изменения в Git или сделайте резервную копию проекта.
2. Остановите запущенный сервер (`Ctrl+C`). Скопируйте `vmc-cipher-b.patch` в корень проекта — там, где находятся `package.json`, `src` и `app`.
3. Откройте PowerShell в этой папке и выполните **проверку**:

```powershell
git apply --check .\vmc-cipher-b.patch
```

Успешная проверка ничего не печатает и не изменяет файлы. Если есть `patch does not apply`, `No such file` или `already exists`, не выполняйте следующую команду. Убедитесь, что выбрана правильная папка. Если код уже изменялся после исходной поставки, передайте текст ошибки и актуальные файлы: патч нужно адаптировать. Параметры принудительного применения и `--reject` не требуются.

4. После успешной проверки примените:

```powershell
git apply .\vmc-cipher-b.patch
```

5. Если зависимости ещё не установлены, выполните `npm ci`. Затем проверьте, пересоберите и запустите:

```powershell
npm run typecheck
npm run test:core
npm run build:standalone
npm run start:standalone
```

Каждую следующую команду выполняйте после успешного завершения предыдущей. Нужен Node.js 22.13 или новее, как в исходном проекте. Откройте [локальное приложение](http://localhost:3000). Если был задан другой PORT, используйте его. Просто перезапустить старую `release/server.mjs` недостаточно: **build:standalone обязателен**, потому что патч содержит исходники, а не готовый release.

Откройте пару → **Индикаторы** → **VMC Cipher B · VuManChu** → **+**. Для настройки нажмите **Настройки** у экземпляра либо его название под графиком.

## Git Bash / Linux / macOS

Команды те же; путь к патчу можно записать `./vmc-cipher-b.patch`. При запуске через Docker после применения выполните `docker compose up --build -d`, чтобы пересобрать образ.

## Откат

Если после применения эти файлы ещё не редактировались:

```powershell
git apply -R --check .\vmc-cipher-b.patch
git apply -R .\vmc-cipher-b.patch
npm run build:standalone
```

При ошибке проверки обратного патча остановитесь и используйте сохранённый Git-коммит/копию для выборочного восстановления. Патч не отправляет изменения в удалённый репозиторий и не публикует сайт. Чтобы поделиться обновлением в своём репозитории, отдельно просмотрите diff, создайте commit и push обычным способом.
