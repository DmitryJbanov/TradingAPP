# Расширение DiVMoney

Перед изменениями сверяйтесь с [картой проекта](PROJECT_MAP.md) и проверяйте текущие реализации, а не старые патч-гайды. В приложении есть два runtime-адаптера — hosted в `app/` и автономный Node.js в `standalone/`; доменные типы и UI должны оставаться общими.

## Добавление инструмента

1. Добавьте инструмент и его метаданные в `src/domain/catalog.ts`.
2. Преобразуйте upstream ID и ответ провайдера на сервере в общие `Market`/`Candle` типы.
3. Обновите проверку входных параметров, интерфейс и тесты. Не принимайте произвольные URL от браузера и не отдавайте секреты клиенту.
4. Если инструмент требует иных свечных интервалов, согласованно обновите domain type, валидатор API и provider mapping.

## Добавление индикатора

1. Разместите численный расчёт без UI в `src/indicators/` и определите прогрев, пропуски и поведение незакрытой свечи.
2. Зарегистрируйте индикатор в `src/domain/workspace.ts` и подключите hook/rendering/settings в соответствующих местах.
3. Храните только сериализуемые параметры экземпляра. Chart API объекты и canvas references нельзя сохранять в localStorage.
4. Уважайте `enabled`/visibility, настройки вида и удаление экземпляров. Добавьте тесты на вычислитель и настройку; проверьте hosted и standalone пути.

## Изменение разметки и настроек

Разметка должна хранить рыночные координаты времени/цены, а не пиксели. При изменении схемы localStorage добавьте миграцию либо версионируйте ключ. Общую тему и верхнюю навигацию меняйте в общих компонентах, чтобы страницы не расходились по виду.

## Проверка

Используйте `npm run typecheck`, `npm test`, `npm run build:standalone` и `npm run test:smoke` по необходимости. Для Python CoinGlass сервиса есть `python -m unittest discover -s services/coinglass -p "test_*.py"`. Node.js 22.13+ обязателен для основного проекта. Не используйте `docs/APPLY_*.md` как шаблон для разработки текущей версии.
