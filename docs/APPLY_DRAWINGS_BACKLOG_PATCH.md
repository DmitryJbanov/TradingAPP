# Рисование на графике и страница беклога

Патч tradingapp-drawings-backlog.patch рассчитан на проект после применения tradingapp-preferences.patch и tradingapp-symbol-search.patch (исходная база main: 126c1fbe90e233c5c614ada5549aa18c2502a763). Применять прежние патчи повторно не нужно.

В корне проекта выполните последовательно:

```bash
git apply --check tradingapp-drawings-backlog.patch
git apply tradingapp-drawings-backlog.patch
npm run typecheck
npm run test:core
npm run build:standalone
```

Остановите старый процесс сервера и запустите `npm run start:standalone`. Для Docker используйте `docker compose up -d --build`.

## Беклог

Полный список задач находится на /backlog. Страница поддерживает прямое открытие и перезагрузку в standalone и имеет маршрут app/backlog/page.tsx для основной сборки. На главной показаны первые три пункта с разделителями и ссылкой «Полный беклог». Ссылка также добавлена в навигацию.

Единственный источник списка — массив backlog в src/domain/backlog.ts. Добавляйте, удаляйте и переставляйте объекты с уникальным id, title и description, затем пересобирайте приложение. Обе страницы используют этот массив. Выполненные backlog-section и chart-drawing-tools удалены; осталась интеграция CoinGlass. Для пустого списка предусмотрено отдельное сообщение.

## Разметка графика

Над графиком доступны «Навигация», «Кисть», горизонтальная и вертикальная линии, прямоугольник и Фибоначчи.

Выберите цвет и инструмент. Для линии достаточно нажатия в области свечей; можно удерживать и перемещать указатель перед отпусканием. Для кисти, прямоугольника и Фибоначчи нажмите, перетащите и отпустите указатель. Кисть поддерживает мышь, перо и сенсорный ввод через Pointer Events. Область рисования ограничена основной панелью свечей; панели индикаторов и шкалы не являются областью разметки.

Фибоначчи рисует уровни 0%, 23,6%, 38,2%, 50%, 61,8%, 78,6% и 100% с ценами, от начальной точки к конечной. Обратное направление также поддерживается. Горизонтальная и вертикальная линии продолжаются на всю область свечей.

Esc отменяет текущий незавершённый рисунок и включает навигацию. Кнопка «Навигация» возвращает обычное масштабирование и прокрутку. «Отменить добавление» удаляет последний оставшийся объект. В разделе «Объекты» можно изменить цвет конкретного объекта или удалить его. Перетаскивание уже созданных объектов и изменение их геометрии не входят в эту версию: удалите объект и нарисуйте заново.

Разметка хранится в localStorage браузера отдельно для каждой пары и таймфрейма: vector.drawings.v1:<symbol>:<timeframe>. Spot/Futures имеют разные идентификаторы. Переход между парами и таймфреймами не удаляет разметку; возвращение восстанавливает её. Координаты хранятся как время и цена, а не пиксели. Обновление свечей, масштаба и количества истории сохраняет положение объектов. Для точек между свечами используется интерполяция, за пределами загруженной истории — интервал текущего таймфрейма. Объекты вне текущего видимого диапазона могут быть не видны.

Лимиты: 200 объектов на пару/таймфрейм и 2000 точек на мазок кисти. При заполнении или блокировке localStorage появляется предупреждение; текущая разметка остаётся в памяти вкладки. Между браузерами и вкладками синхронизации нет. Очистка данных сайта удаляет сохранённую разметку. Общие настройки индикаторов из предыдущего патча сохраняются независимо от рисунков.

## Проверки

Пройдены TypeScript, 44 автоматических теста, standalone-сборка и HTTP smoke-тест, включая /backlog и /backlog/. В Chromium на демонстрационных свечах проверены прямое открытие беклога, создание всех пяти типов рисунков, восстановление после перезагрузки, изоляция по паре и таймфрейму, изменение цвета, удаление и отмена добавления. Ошибок JavaScript на страницах не выявлено. Визуально проверена отрисовка на графике. Для патча отдельно выполнен git apply --check на чистой базе после предыдущего патча.
