# Обновление свечей, беклог и ресурсы

Патч подготовлен для коммита `864b94c30bfb74d17dfd1f4e851f80002bf6b1ea` репозитория DmitryJbanov/TradingAPP. Все команды выполняйте из корня проекта, где находится package.json. Сначала сохраните свои изменения коммитом или отдельной копией.

1. Поместите `tradingapp-live-backlog.patch` в корень проекта.
2. Проверьте применимость: `git apply --check tradingapp-live-backlog.patch`.
3. Если проверка прошла без ошибок: `git apply tradingapp-live-backlog.patch`.
4. Соберите: `npm run build:standalone`.
5. Остановите прежний сервер (Ctrl+C) и запустите: `npm run start:standalone`.

При ошибке проверки не используйте принудительное применение: текущие файлы отличаются от основы патча. Для Docker вместо шагов 4–5: `docker compose up -d --build`.

## Как изменить список доработок

Откройте `src/domain/backlog.ts`. Каждый объект массива `backlog` — одна запись на главной: `id` должен быть уникальным, `title` задаёт заголовок, `description` — пояснение. Добавляйте или удаляйте объекты, меняйте их порядок. После сохранения пересоберите и перезапустите приложение командами выше. `future_update.txt` содержит только указатель на этот файл.

## Поведение обновления

Полная история загружается при открытии пары, изменении глубины/таймфрейма и ручном обновлении. Затем видимая вкладка опрашивает `/api/candles/latest` каждые 30 секунд. Сервер возвращает текущую и предыдущую свечу, чтобы закрытие предыдущей также уточнялось. История на клиенте накапливает изменения по времени свечей и ограничивается выбранной глубиной. При пропусках или смене источника загружается заново. В скрытой вкладке опрос приостанавливается; при возврате следующий опрос выполняется в пределах 30 секунд, если браузер не задерживает таймеры.

DEMO-данные синтетические и не обязаны менять цену при каждом опросе. Реальный API также может вернуть неизменившуюся цену. Дополнительные таймфреймы VMC/SMC пока могут запрашивать полную историю; их оптимизация — отдельная доработка.

Ресурсы, сетевые требования и команды замера: [OPERATIONS.md](OPERATIONS.md#ресурсы-и-нагрузка).
