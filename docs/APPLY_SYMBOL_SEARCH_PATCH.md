# Динамический поиск торговых пар

Патч `tradingapp-symbol-search.patch` применяется после `tradingapp-preferences.patch` к базе main `126c1fbe90e233c5c614ada5549aa18c2502a763`. Он сохраняет 4H по умолчанию, общие настройки индикаторов и обновление свечей каждые 30 секунд.

В корне проекта: `git apply --check tradingapp-symbol-search.patch`, затем `git apply tradingapp-symbol-search.patch`.

Проверка: `npm run typecheck`, `npm run test:core`. Сборка: `npm run build:standalone`. Перезапустите сервер командой `npm run start:standalone` после остановки старого процесса. Для Docker: `docker compose up -d --build`.

На главной странице и странице графика появился блок «Поиск торговых пар». Введите базовый актив или пару (например, BTC/USDC); запрос отправляется после паузы 300 мс. Поиск охватывает активные Binance Spot и бессрочные Binance USDⓈ-M Futures, включая пары, отсутствующие в исходном каталоге. Фильтр позволяет выбрать рынок. Максимум 60 результатов; для более длинного списка уточните запрос. При недоступности одного рынка доступны результаты другого с предупреждением. В режиме DATA_MODE=demo биржевой поиск недоступен.

Нажатие результата открывает график с историей, индикаторами и обновлением последней свечи. Прямая ссылка также работает без предварительного поиска. Spot и Futures различаются в URL: например, `/pair/BTCUSDC` и `/pair/FUTURES%3ABTCUSDC`. Старая ссылка HYPEUSDT остаётся фьючерсной; спотовая пара, если доступна, использует SPOT:HYPEUSDT. Отдельный список котировок на главной странице остаётся подборкой популярных инструментов; произвольные пары доступны через новый поиск.

Кнопка ☆ добавляет результат в избранное. Раздел «Избранные пары» под поиском содержит ссылки на все сохранённые инструменты, включая отсутствующие в подборке. Избранное хранится в прежнем vector.favorites.v1 в localStorage текущего браузера. Spot и Futures сохраняются отдельно. При запрете localStorage сохранение после перезагрузки недоступно.

Новый GET /api/symbols принимает q и market=all|spot|futures. Каталоги exchangeInfo кэшируются на сервере на час, одновременные запросы объединяются. Листинги и делистинги отражаются после истечения кэша. API свечей проверяет новые идентификаторы по каталогу и возвращает метаданные инструмента. Ошибка каталога/котировок новой пары даёт 503, неизвестная или неактивная пара — 400; синтетические свечи для новых пар не создаются. Доступность рынков зависит от доступа сервера к Binance. API-ключ для этих публичных данных не требуется. Поиск акций, Forex и других бирж в эту доработку не входит.

Из src/domain/backlog.ts удалён выполненный dynamic-symbol-search. Остаются chart-drawing-tools, backlog-section и coinglass-liquidation-map. Меняйте массив backlog в этом файле, чтобы обновить список задач.

Проверено: 41 автоматический тест, TypeScript, standalone-сборка и HTTP smoke-тест. Новые тесты используют подставные ответы биржи: проверяют фильтрацию каталога, разделение рынков, частичную недоступность, прямую загрузку истории и последних свечей, отклонение неизвестных пар и отсутствие DEMO-подмены при сбое. Реальное соединение с Binance и интерактивная проверка в браузере не выполнялись.
