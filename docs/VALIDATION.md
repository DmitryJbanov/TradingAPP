## Что проверяют core-тесты

1. OHLC high/low-инварианты, временные интервалы, одинаковая текущая demo-цена между всеми таймфреймами.
2. Формула отклонения от цены курсора, знак и защита от деления на ноль.
3. Разные UTC-положения лондонской сессии зимой/летом, нью-йоркский DST, выходные.
4. Валидация symbol/interval, запрет POST, неизвестный маршрут, provenance демоданных.
5. Нормализация успешного ответа Binance, отсутствие ложной метки live на остальных инструментах, HTTP 429 → demo fallback.

## Границы подтверждения

Проверка реального внешнего API отражает конкретный момент и среду; дальнейшая доступность определяется провайдером и сетью. В одном проверочном запуске общий ticker-запрос не успел/не удался и вернул DEMO, при этом свечи были live. Запрос котировок затем сокращён до каталога из 30 символов, но в повторном запуске таблица также перешла в DEMO; live ticker в этой среде не подтверждён. Приложение допускает разные статусы источника у таблицы и графика и показывает их отдельно.

Twelve Data не проверялся с настоящим ключом: ключ не предоставлен. Контейнер Docker в этой среде не запускался; автономный Node runtime и его HTTP API проверены непосредственно. Браузерные/E2E проверки, перетаскивание мышью, визуальная проверка разных экранов и автоматический аудит доступности не выполнялись. Масштабирование и crosshair настроены через API библиотеки и проверены статически/сборкой.

В standalone build есть предупреждение о размере главного JS bundle (~533 KB без gzip, ~168 KB gzip). Это не ошибка сборки; дальнейшее разделение chart-модуля возможно для оптимизации первой загрузки.

Команды для повторения:

```bash
npm ci
npm run typecheck
npm run test:core
npm run build:standalone
npm run test:smoke
```

Для проверки с реальными сетевыми источниками в bash:

```bash
SMOKE_LIVE=1 npm run test:smoke
```

Smoke-test запускает временный сервер на 127.0.0.1:3093 и завершает его после проверки. Внешняя проверка не требует ключа Binance, не совершает торговых операций.
