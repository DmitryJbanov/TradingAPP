# DiVMoney · Market Terminal

**Версия 0.7 BETA.** DiVMoney — веб-терминал для наблюдения за рынками и технического анализа. Проект показывает котировки, свечные графики и аналитические инструменты в едином интерфейсе на русском языке.

## Обновление 0.7 BETA

Страница графика получила компактную верхнюю панель, поиск инструмента в списке справа, объединённую метку текущей цены и таймера свечи, а также обновлённый Pine Editor с регулируемой шириной. В панели индикатора значения у курсора отображаются только при наличии данных.

См. [управление графиком и FRVP](docs/CHART_TOOLS.md): линейка, создание и изменение фигур, часовой пояс, кеш пар и автоматическое обновление карт.

## Быстрый запуск

### Node.js

Нужен Node.js 22.13 или новее. В корне проекта выполните:

```bash
npm ci
npm run build:standalone
npm run start:standalone
```

Откройте <http://localhost:3000>. Для запуска готовой сборки без npm-зависимостей используйте `node release/server.mjs`.

### Docker

Нужны Docker Engine и Docker Compose v2. Из корня проекта:

```bash
docker compose up -d --build
```

Standalone поддерживает саморегистрацию пользователей, общий редактируемый профиль и личные профили. Перед публикацией задайте `PUBLIC_ORIGIN` в `.env`, например `https://terminal.example.com`, и запускайте за HTTPS reverse proxy. `SESSION_COOKIE_SECURE=true` оставляйте включённым для публичного сервера. Учётные записи и профили хранятся в постоянном томе `divmoney-data`; не удаляйте его при обновлении.

Откройте <http://localhost:3000>. Вместе с терминалом запустится сервис CoinGlass с браузерным сборщиком данных.

## Возможности

- [Пресеты параметров индикаторов](docs/INDICATOR_PRESETS.md): сохранение, управление и выбор настроек по умолчанию.
- Каталог криптовалют, акций, индексов и валютных пар; поиск, избранное, фильтры и сортировка.
- На главной показаны время UTC и Москвы, а также текущее значение Fear & Greed со ссылкой на страницу индекса.
- Свечной график с выбором таймфрейма, истории, масштаба и темы.
- Индикаторы и разметка графика: VMC, DRZ, SMC, Fair Value Gap · LuxAlgo, Sonarlab Order Blocks, Stoch RSI, MTM и Fixed Range Volume Profile.
- [Pine Editor](docs/PINE_SCRIPT.md): собственные индикаторы и стратегии на Pine Script v4/v5/v6 через PineTS; для v4 выполняется совместимый перевод в v5 перед запуском. Доступны настройка входных параметров, отображения и цветов элементов, иконки и её цвета, импорт/экспорт и тестер стратегий с описанными ограничениями совместимости.
- Данные CoinGlass: Heatmap Model 3, уровни ликвидаций и их визуализация на графике.
- Отдельные страницы Fear & Greed Index и RSI Heatmap по top 50.
- [Киты Hyperliquid](docs/WHALES.md): общий обзор, профили кошельков, список отслеживания, фоновое обновление позиций и исполнений; сортировка полей публичного рейтинга по заголовкам столбцов.
- Профили пользователей: саморегистрация, общий профиль для синхронной рабочей области, личные профили и SQLite-хранилище. Подробности безопасности, настройки reverse proxy и резервное копирование — [эксплуатация](docs/OPERATIONS.md).
- Источник фьючерсного графика выбирается в его заголовке: Binance, OKX, Bybit или MEXC. Свечи, поиск, котировки и данные индикаторов используют выбранную биржу; Twelve Data для акций, индексов и валютных пар подключается серверным API-ключом.

Если источник недоступен или не настроен, приложение может показать синтетические данные с отметкой DEMO. Для настройки Twelve Data задайте `TWELVE_DATA_API_KEY`; остальные параметры приведены в [`.env.example`](.env.example).
