# Vector Market Terminal

Самостоятельное веб-приложение для просмотра торговых инструментов: React + TypeScript, собственный backend и свечные графики TradingView Lightweight Charts. Интерфейс на русском. Исходники и готовая автономная сборка входят в поставку.

## Быстрый запуск

### Docker Compose

Требуются Docker Engine и Compose v2. Из корня проекта:

```bash
cp .env.example .env
docker compose up -d --build
```

Откройте http://localhost:3000. По умолчанию порт опубликован только на loopback. Для другого компьютера используйте reverse proxy или явно измените привязку в compose.yaml.

```bash
docker compose ps
docker compose logs -f --tail=100 terminal
docker compose down
```

Приложение не требует PostgreSQL, Redis, аккаунта TradingView или платёжных реквизитов.

### Без Docker: готовая сборка

Требуется Node.js 22.13+ (рекомендуется актуальная версия Node 22). В поставке есть `release/`; npm-зависимости для запуска не нужны:

```bash
node release/server.mjs
```

Откройте http://localhost:3000. Переменные можно передать окружением или через файл:

```bash
cp .env.example .env
node --env-file=.env release/server.mjs
```

На Windows те же команды выполняются в PowerShell; вместо `cp` можно использовать `Copy-Item`.

### Собрать из исходников

```bash
npm ci
npm run build:standalone
npm run start:standalone
```

`build:standalone` создаёт `release/public/` и `release/server.mjs`. Этот каталог можно перенести на другой сервер с Node.js 22, без установки npm-пакетов. Все assets локальные: браузеру не нужны CDN.

## Что реализовано

### Главная страница

- Каталог 30 популярных криптовалютных пар к USDT, 8 акций, 3 индексов и 3 валютных пар.
- Четыре обзорные карточки, текущие цены, дневная динамика, объём и диапазон high/low.
- Вкладки по типу рынка и общий список; текстовый поиск по символу и названию.
- Фильтры: избранное, направление движения, сектор, источник, минимальная/максимальная цена, минимальный объём. Сортировка по объёму, росту, падению, цене и названию. Выбор 10/20/30/всех строк.
- UTC-часы и временная шкала с текущим положением, зонами Азии, Лондона и Нью-Йорка.
- Реальный статус своего backend, uptime процесса, статусы источников, журнал INFO/WARN/ERROR с фильтром и паузой.

Каталог криптовалют отобран вручную. По умолчанию строки сортируются по объёму внутри каталога. Это не динамический рейтинг всей капитализации крипторынка.

### Страница инструмента

- Адреса вида `/pair/BTCUSDT`, свечи OHLC и объём, 400 свечей истории.
- Таймфреймы 15 минут / 1 час / 4 часа / 1 день.
- Независимое масштабирование: перетаскивайте нижнюю ось времени и правую ось цены.
- Колесо мыши масштабирует, перетаскивание рабочей области перемещает график. Двойной клик по шкале сбрасывает её; кнопка «Сбросить масштаб» возвращает обе оси.
- Подвижное пунктирное перекрестие. Процент отклонения от цены курсора показан у вертикальной линии над нижней осью, дополнительно возле горизонтальной линии.
- Формула: `(текущая цена / цена курсора − 1) × 100`. Положительное значение означает, что текущая цена выше цены курсора. За текущую берётся close последней полученной свечи, не отдельный streaming tick.
- Поиск и избранное в боковом списке для перехода между инструментами.
- Принудительное обновление обходит кеш сервиса. Автообновление свечей каждые 15 секунд, котировок каждые 30 секунд, только пока вкладка видима.
- Три темы сайта, акцент, независимые цвета фона графика, сетки, подписей и свечей.

### Менеджер индикаторов

Реализованы каталог, поиск, добавление экземпляров, порядок, переключатель видимости, период, цвет, удаление и сохранение отдельно для каждого инструмента. **В этой версии расчётов индикаторов и торговых сигналов нет.** Интерфейс явно показывает «Расчёт не подключён». Переключатель сохраняет желаемую видимость будущего расчёта.

Приложенный `test.txt` сохранён без изменения логики в `references/nadaraya-watson-original.pine`. Это стратегия Pine Script, а не браузерный JavaScript. Её исполнение и перенос в TypeScript пока не выполнялись.

## Источники и достоверность

`DATA_MODE=auto` — криптовалюты загружаются сервером с публичного Binance Market Data API. Ключ не требуется. Акции, индексы и forex могут загружаться через Twelve Data после настройки `TWELVE_DATA_API_KEY` и при наличии доступа к инструменту на вашем тарифе.

Если API недоступен, инструмент отсутствует или ключ не указан, приложение использует **синтетические данные с меткой DEMO**. Это не исторические и не текущие биржевые котировки. На графике появляется отдельный баннер. Фильтр «Источник → API» скрывает демостроки.

`DATA_MODE=demo` — воспроизводимый локальный режим без внешних запросов. Текущие demo-close согласованы между таймфреймами; OHLC получаются из общей базовой последовательности.

Метка API означает получение ответа поставщика. Она не гарантирует отсутствие задержки на стороне биржи/тарифа. Binance change — скользящие 24 часа; Twelve Data change — изменение относительно предыдущего закрытия торговой сессии. Для forex и индексов торговый объём может отсутствовать.

Торговые сессии — ориентиры валютной активности: Токио 09:00–18:00, Лондон 08:00–17:00, Нью-Йорк 08:00–17:00 по местному времени. DST учтён через IANA timezone/Intl; выходные закрыты. Биржевые праздники, перерывы и точное расписание торгов отдельного инструмента не учитываются.

## Конфигурация

| Переменная            | По умолчанию | Назначение                          |
| --------------------- | ------------ | ----------------------------------- |
| `DATA_MODE`           | `auto`       | `auto` или `demo`                   |
| `TWELVE_DATA_API_KEY` | пусто        | Серверный ключ акций/индексов/forex |
| `PORT`                | `3000`       | HTTP-порт standalone Node           |
| `HOST`                | `0.0.0.0`    | Адрес прослушивания Node            |

Ключи не передаются браузеру, не включаются в логи и не хранятся в репозитории. `.env.example` содержит только пример. В Docker Compose параметры читаются из `.env` при запуске; после изменений выполните `docker compose up -d --force-recreate`.

Избранное, темы и менеджер индикаторов хранятся в localStorage текущего браузера. Котировки и последние логи находятся в ограниченном кеше памяти процесса. После рестарта они заполняются заново. Между устройствами настройки не синхронизируются.

## Разработка и проверки

```bash
npm run typecheck
npm run test:core
npm run build:standalone
```

Для автономной разработки: соберите frontend и запустите standalone, повторяйте сборку после изменений. Для HMR можно использовать основной Vinext dev-режим: `npm run dev` (он запускает Vite/локальную эмуляцию Worker). Продакшен standalone не зависит от Vinext, Cloudflare или сервиса публикации.

Основная hosted-сборка: `npm run build`, результат в `dist/`. Она нужна только для Cloudflare Worker-compatible размещения. Не путайте её с переносимым `release/`.

## Границы первой версии

Нет исполнения Pine Script, индикаторных расчётов, рисования, Фибоначчи, нескольких графиков на одном экране, WebSocket tick-stream, выставления ордеров, аккаунтов или постоянной БД. Для будущих панелей, рисунков и индикаторов определены сериализуемые контракты и точки расширения. Ни одна из этих будущих функций не представлена как уже работающая.
