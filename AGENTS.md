# DiVMoney: быстрый вход

Сначала прочитайте `docs/PROJECT_MAP.md`, затем только файлы нужной подсистемы.
Не сканируйте весь репозиторий, если известен компонент или маршрут. Используйте
`rg -n` для символов и ограниченные фрагменты файлов для контекста.

- Исходники: `src/`, маршруты `app/`, переносимый сервер `standalone/`.
- Не анализируйте `release/`, `node_modules/`, `.test-build/`, архивы и `*.patch`
  без прямой необходимости: это зависимости, результаты сборки или старые поставки.
- Читайте и записывайте текст как UTF-8 (PowerShell: `Get-Content -Encoding utf8`).
- Перед изменениями проверьте `git status --short`; сохраняйте пользовательские правки.
- Ключи `vector.*` в localStorage намеренно сохранены для совместимости.
- UI-изменения обычно не требуют новых зависимостей. Общие компоненты исправляйте один раз.
- Проверки Windows: `npm.cmd run typecheck`, `npm.cmd test`;
  переносимая сборка: `npm.cmd run build:standalone`, затем `npm.cmd run test:smoke`.
- Обновляйте карту при изменении архитектуры; не храните в ней копии исходников.
